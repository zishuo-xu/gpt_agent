# MyAgent — 功能文档

> 面向使用者的功能说明：这个 Agent 怎么用。

## 1. 启动方式

shell 层只有两个命令：

| 命令 | 作用 |
|---|---|
| `myagent` | 进入交互 CLI（任务的唯一入口） |
| `myagent --web` | 启动本地 Web 界面（默认 http://localhost:3000） |

进入 CLI 后，直接打字就是聊天干活；所有操作通过内部命令完成（完整列表见 §2.3）。

## 2. CLI 交互

### 2.1 对话与干活

直接用自然语言下达指令。Agent 会自主探索代码库、编辑文件、运行命令并自我修正。

- 复杂任务时自动维护 **todo 清单**，实时显示在界面侧栏：已完成 / 进行中 / 待办
- 编辑文件后展示 **diff 高亮**，改在哪一目了然
- 派生**子代理**探索代码时，主对话中显示可折叠卡片（任务名、工具调用次数、消耗 tokens），点开可看过程

### 2.2 打断

- **直接打字**：消息排队，Agent 当前这轮做完后响应（软打断）
- **Esc**：立即中止模型生成与当前工具（硬打断）。内置文件编辑保证原子性，不会留下半个文件；Bash 会终止整个进程组，但已经发生的外部副作用无法自动撤销，界面会明确提示

### 2.3 会话内命令

| 命令 | 作用 |
|---|---|
| `/run <任务> [--until 07:00] [--budget 5] [--permission trust]` | 启动任务：无人值守迭代就加约束，一次性小任务什么都不加（干完自然停）；任务在当前会话持续运行，终端保持开着即可 |
| `/sessions` | 查看会话/任务列表 |
| `/switch <id>`（别名 `/resume`） | 切换/恢复会话 |
| `/permission <strict\|normal\|trust>` | 切换权限档 |
| `/compact` | 手动触发上下文压缩 |
| `/init` | 初始化项目：扫描后生成 AGENTS.md 草稿，你确认/编辑后保存（进入陌生项目默认零操作，不会自动扫描） |
| `/cost` | 查看本次会话消耗（token 为主） |
| `/config ...` | 查看/修改配置（与 Web 设置页同一套） |

## 3. 权限与批准

### 3.1 三个档位

- **strict**：Edit / MultiEdit / Write / Bash 全部要你确认；已记住的 allow 规则在本档不生效——适合陌生项目
- **normal**（默认）：读操作与 Edit / MultiEdit 自动放行；Write 询问；Bash 仅安全白名单（跑测试、git status 等）自动放行，其余询问
- **trust**：除 deny 与显式 ask 规则外自动执行——适合无人值守

### 3.2 批准弹窗（看完再批）

- **改文件（Edit/Write）**：批准前先展示真实 diff（改动块 ±3 行，大改动折叠可展开）；新文件显示前 20 行预览
- **跑命令（Bash）**：卡片 = 命令原文 + 一行风险翻译（"将修改 package.json 与 lock 文件""⚠ 递归删除目录"）+ Agent 的目的
- **批准选项**：仅这一次 / 本次会话都允许 / 本项目永久允许 / 全局永久允许 / **拒绝并留言**（附一句纠正，Agent 立刻换方案）
- normal 档下 Edit 自动放行（有 EditJournal 与事后 diff 可查），审批弹得少但每次都值得细看

规则随时可在 Web 设置页查看、增删。

规则优先级固定为 `deny > strict 档 > ask > allow > trust 档 > normal 默认策略`。deny 永远直接拒绝，不提供临时强制放行。

### 3.3 无人值守安全

- 审批请求超时（默认 5 分钟）无人响应 → 自动拒绝，Agent 换路继续或收尾
- 黑名单规则任何档位都不豁免

## 4. 无人值守模式

```bash
# 交互界面中输入：
/run 继续迭代 RAG 项目，优先完善检索评估 \
  --goal "pnpm test:eval 的 recall@5 ≥ 0.80" \
  --bounds "不改 src/api/ 目录，不动数据库 schema" \
  --until 07:00 --budget 5 --permission trust
# 任务在当前会话持续运行，终端保持开着即可
```

- **任务三要素**：`--goal` 机器可判定的验收命令（Agent 每轮自证）；`--bounds` 负面清单（路径类编译为 deny 规则并在启动前展示确认一次；语义类注入强提示约束）；时间/预算盒
- **时间盒**：到 07:00 自动收尾；**预算盒**：花费到 5 元自动收尾
- **优雅终止**：分阶段警告（阶段可配，默认剩余 30 分钟收窄范围 → 10 分钟进入收尾 → 2 分钟只输出总结）。优先把代码恢复到可编译状态；只能通过编辑日志撤销 Agent 自己且未被再次改动的编辑，无法安全恢复时保留现场并明确报告
- **模型容错**：遇限流/断网自动指数退避重试，可配备用模型降级；彻底失败时通知你并优雅收尾保留现场
- **权限档**：`--permission trust` 仅任务期生效，任务结束回落原档位
- **收尾三件套**：总结报告（含验证结果前后对比）+ todo 快照（明天接着干）+ 记忆写入
- **选任务原则**：只把"验收标准机器可判定"的任务放过夜（测试/lint 过没过）；需要人脑判断"好不好"的任务不适合无人值守
- **通知**：页面内为主——状态变化、标签页标题提示（如 `(1) 等待审批`）；外部 webhook 推送（企业微信/Bark/邮件）为后续扩展，不配也能完整使用
- **远程监控**：浏览器打开 Web 界面（手机也行）看实时进度；审批请求出现在页面上，点一下放行；超时无人理会则自动拒绝换路继续

## 5. Web 界面

### 5.1 监控台（首页）

所有会话的状态卡片：项目名、任务标题、运行状态、todo 进度条、累计花费、已运行时长。点卡片进入会话详情。

### 5.2 会话详情

- 左侧：完整对话流（文本、工具调用、diff 高亮、子代理卡片）
- 右侧：todo 面板 + 消耗卡（token 口径）+ 会话信息
- 底部：输入框（可发送消息或批准请求）；`回放模式` 可从第一条事件开始复盘 Agent 的完整决策过程

### 5.3 记忆面板

浏览 Agent 沉淀的记忆：项目约定（conventions）、踩坑记录（pitfalls）、架构决策（decisions）、全局偏好（preferences）。可直接编辑、删除；每次 Agent 自动写入都有记录（"它学到了什么"时间线）。

### 5.4 成本透明（轻量，非独立页面）

- 每轮对话末尾一行小字：`本轮 12.4k in / 1.8k out · 缓存命中 78% · 累计 89k`（token 为主，金额为括号小字）
- 会话卡片与侧栏显示累计消耗；`/cost` 命令随时查
- 完整数据记录在会话文件中，需要深度分析时可随时导出

### 5.5 设置页

- 模型配置采用供应商列表 + 详情双栏：支持启用/禁用、Anthropic Messages 与 OpenAI-compatible Chat Completions、自定义 Base URL 和 API Key
- 每个供应商可维护多个模型；每个模型有独立“测试连接”，通过一次最小真实调用验证认证、接口路径、模型名称并显示延迟
- 主模型 / 压缩模型 / 探索模型从已启用供应商的模型列表中分别选择
- 权限规则表（allow/ask/deny，增删改）
- 行为参数（压缩阈值、审批超时等）
- 服务器（监听地址、访问密码）；通知 webhook（后续扩展预留）
- 全局 / 当前项目两个作用域切换

## 6. 记忆

- **项目记忆**：`AGENTS.md`（仓库根目录，随 git 共享；由 `/init` 生成草稿、你确认后生效）+ 仓库内 `.myagent/memory/` 下的 conventions / pitfalls / decisions（可随仓库共享）；会话、trace 等机器状态存在家目录，不进仓库
- **全局记忆**：`~/.myagent/MEMORY.md`（跨项目偏好）
- Agent 干活中学到稳定事实（如"本项目测试命令是 pytest -x""Chroma 连接要加超时"）会**自主写入记忆**，下次会话自动带上
- 跨项目联想：新会话会看到他项目记忆的标题索引，相关时 Agent 主动调取全文

### 6.1 记忆治理（轻治理三层防线）

1. **写入可见**：记忆面板的"它学到了什么"时间线，每次自动写入均可审计
2. **写入自律**：模型只写稳定事实（命令、约定、已验证的坑），推测性内容标"待验证"
3. **删除即治理**：面板一键删除，或对话中指出错误由 Agent 自己修正；不做写入审批制（避免成为新的打断源）。错记忆会在下次使用时被 Agent 自行发现并修正

## 7. 多模型

- 主循环、压缩摘要、子代理探索可分别配置不同模型
- 支持 Anthropic 与任意 OpenAI 兼容端点（DeepSeek / Kimi / GLM）
- 每次调用自动记录 token 与费用，对话末尾小字或 `/cost` 可查

## 8. 会话管理

- 所有会话自动持久化，崩溃不丢（最多丢最后一行）
- `/sessions` + `/switch` 或 Web 首页选择任意历史会话继续
- todo 状态随会话恢复，未完成的任务接着干
